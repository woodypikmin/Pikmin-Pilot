Pikmin Pilot Pairing Setup — Windows
=====================================

用途：iOS 17.4–26.x 第一次只用一次 USB，把 RPPairing 直接寫進 Pikmin Pilot。

前置：
1. Windows 安裝 Apple iTunes / Apple Mobile Device USB driver。
2. iPhone 已安裝 Pikmin Pilot。
3. iPhone 解鎖、用 USB 接電腦，跳出「信任這部電腦」時按信任。

使用：
1. 開啟 PikminPilotPairingSetup.exe。
2. 選擇你的 iPhone。
3. Pairing type 保持 Remote pairing（預設就是它）。
4. 按 Create。
5. 建立成功後，在可安裝 App 清單按「Pikmin Pilot」。
6. 成功後拔掉 USB，開 Pikmin Pilot → START PILOT。

它會把檔案直接放到：
Pikmin Pilot / Documents / rp_pairing_file.plist

不需要 Save to file，也不用使用者自己找 plist。
